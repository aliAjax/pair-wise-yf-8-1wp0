# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、逐段记录检查状态，并生成可放映清单。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 片段状态

每段片段有三种状态，按流程推进：

- **待检查**：新录入片段的初始状态。
- **已处理**：已完成检查或修复，等待最终放行。
- **可放映**：最终可上映状态；只有颜色「正常」且破损「完好」的片段才能标记为可放映，存在偏色或破损时按钮会被拦截。
- 任何状态都可以退回上一步重新核对。

顶部统计实时显示**可放时长**（仅累加「可放映」片段）与**待检查数量**，同时保留总时长和片段数。

## 编辑回退

点击片段上的「改」可以内联修改编号、时长、颜色、破损与备注。只要**编号、时长、颜色或破损情况**发生变化，该片段会自动回到「待检查」；只改备注不会改变状态。

## 顺序与持久化

- 拖拽或上下移动只调整顺序，删除只移除对应片段，其余片段的状态不会丢失。
- 所有数据（胶片卷名、片段内容、状态、顺序、缩略图）都保存在浏览器 localStorage 中，关掉页面再打开仍是同一卷胶片的进度。
- 工具栏可按颜色、状态筛选，或按编号/备注搜索。

## 导出清单

点击「导出清单」会下载 `{胶片卷名}-checklist.txt`，包含胶片卷名、导出时间、总时长、**可放总时长**、片段数，并逐段列出编号、时长、颜色、破损、**当前状态**与备注。
