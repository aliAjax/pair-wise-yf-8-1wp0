# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、逐段留痕检查状态、统计可放时长、筛选颜色偏移并生成试映前核对清单。

## 片段状态

每个片段有三种状态，显示在卡片标题行，可直接在卡片上切换：

- **待检查**：新录入片段的默认状态；改过编号、时长、颜色或破损后也会自动回到此状态。
- **已处理**：破损或偏色已经做过修复处理。
- **可放映**：核对通过，可以放映。存在破损或偏色的片段必须先标为「已处理」，不能从「待检查」直接标为「可放映」（完好无偏色的片段可以直接标记）。

顶部统计显示**可放时长**（状态为「可放映」的片段时长合计）与**待检查**数量。删除片段、上下移动或拖拽调整顺序都不会影响其余片段的状态。

## 编辑

点击片段卡片上的 ✎ 可在左侧表单内联编辑。改动编号、时长、颜色或破损任一项并保存后，该片段状态重置为「待检查」；只改备注或缩略图则保留原状态。

## 导出与保存

- 「导出清单」生成 txt：包含胶片卷、片段数、总时长、**可放总时长**、待检查段数，以及每段的颜色、破损与**状态**。
- 所有数据（含每段状态）保存在浏览器 localStorage，关掉页面再打开仍是同一胶片卷的进度；旧版本保存的数据会自动补认为「待检查」。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
